# EyeTech — экономика внедрения в клинике

Интерактивная модель V1: платформа для приёмов, новая услуга на существующей фундус-камере, покупка камеры, комплект модулей и внешнее заключение.

В подборку входят сценарии, которые проходят заданные условия окупаемости клиники и прибыльности EyeTech. При изменении параметров отрицательные результаты остаются видны в расчёте выбранного варианта.

## Открыть модель

Откройте `index.html` в браузере либо опубликованный сайт GitHub Pages. Сборка, сервер приложений и установка библиотек не нужны.

Все исходные значения — редактируемые гипотезы, а не подтверждённые результаты пилота. Результаты представлены до налогов. Различаются вклад отдельной сделки, подписок и результат компании после общих расходов.

## Работа с параметрами

Параметры и выбранный сценарий сохраняются в localStorage браузера посетителя. Они не отправляются приложением на сервер и не меняют расчёт других посетителей. Кнопка «Скачать расчёт» сохраняет данные в JSON. «Вернуть гипотезы» восстанавливает исходные значения.

Сам код и исходные гипотезы публичного сайта доступны всем. GitHub как хостинг ведёт собственные технические журналы посещений.

## Публикация через GitHub Pages

1. Создать публичный репозиторий `eyetech-clinic-economics` и загрузить файлы из этой папки в ветку `main`.
2. В **Settings → Pages → Build and deployment** выбрать **Deploy from a branch**.
3. Выбрать **main** и папку **/(root)**, нажать **Save**.
4. Дождаться успешной публикации. Ссылка появится в разделе Pages.

При следующих изменениях `index.html` в ветке `main` опубликованная модель обновляется после новой сборки GitHub Pages.

## Метод и проверка

Учитываются дополнительные денежные потоки, ограничения мощности, качество и оплата исследований, труд врача и оператора, внедрение, оборудование и поддержка. Формулы и допущения приведены непосредственно в приложении.

Модель прошла 18 расчётных проверок: баланс денежных потоков, нулевой спрос, общие мощности врача, повторные съёмки, пороги окупаемости, отсутствие двойной оплаты платформы и отбор сценариев. Это проверка реализации расчёта, не клиническая валидация.
